# The ONLY files that ship to Databricks - a real allowlist, not a deny-list.
# databricks_sync_exclude.txt is GENERATED from this + a walk of src/ (see
# generate_exclude() in databricks_deploy.sh) - never hand-edit that file anymore.
#
# A new local-only file (a new provider, a new local-only helper, a study/wip
# script) is EXCLUDED BY DEFAULT the moment it's created - nothing to remember,
# nothing to keep in sync by hand. The trade-off, stated plainly: if a file THIS
# list names starts importing something new, that new file needs adding here too,
# or the Databricks job breaks on import (loud - ModuleNotFoundError - not silent).

# pipeline/{0_land_csv,1_import_to_t1,2_stage_to_t2}.py -> providers.databricks ->

# shared_schema_guards_spark} ; reusable_functions.{helper_datagov,helper_transit}.
